## How to report a game

Enable **Show performance HUD** in the bottle settings before launching the game. Record the HUD values only while the game is actually running:

- FPS
- CPU usage
- GPU usage
- Memory/RAM usage
- Temperature

For a repeatable FPS result, use **Record performance** and play through a consistent scene. When the game ends, record the benchmark's average FPS and 1% low; the benchmark also reports median frame time.

Before submitting a report, fill in only measurements you observed:

- The game title and store.
- The detected DirectX version and renderer used for the run.
- The compatibility status.
- The HUD FPS and any benchmark FPS values.
- The Mac model and chip, macOS version, test date, and tester name or handle.
